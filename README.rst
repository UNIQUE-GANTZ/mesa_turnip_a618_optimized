Mesa Turnip A618 Optimized Source - Vulkan driver optimizations for Adreno 618.

Source
------

This repository is an optimized fork of Mesa Turnip for Adreno 618 GPUs.

Build & install
---------------

The recommended and correct way to build and install this optimized version is by executing the provided build script directly:

.. code-block:: sh

  $ ./build_turnip.sh

This script handles the necessary configurations and build steps specific to this optimized source.
